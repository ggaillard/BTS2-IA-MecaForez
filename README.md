# 🏭 BTS2 SLAM — Séances IA : concevoir, piloter, mesurer, sécuriser

Six séances de TP où le code n'est plus le cœur du travail. Vous êtes stagiaire
SLAM chez **Méca Forez**, PME industrielle fictive de 85 salariés près de
Saint-Étienne. Chaque séance part d'une demande du tuteur et se termine par une
preuve écrite.

> **Module** IA Méca Forez · **classe** BTS2 SIO SLAM (`BTS2-SLAM-2026`) · suivi dans le
> [portail](https://ggaillard.github.io/portail-bts/).

| Verbe | Ce qu'il veut dire ici |
|---|---|
| **Concevoir** | transformer un besoin flou en spécification qu'un humain ou un agent peut exécuter |
| **Piloter** | faire travailler un outil (agent, LLM, automate) et garder la main sur ce qu'il fait |
| **Mesurer** | prouver par des chiffres qu'une solution marche, et dans quelle proportion elle se trompe |
| **Sécuriser** | trouver ce qui peut mal tourner et le corriger avant la mise en service |

## Démarrer

1. Créez votre copie du dépôt (bouton **Fork**), puis ouvrez-la dans **Codespaces**
   (bouton **Code → Codespaces → Create codespace**). L'environnement .NET 10 et
   Copilot Chat s'installent seuls.
   Pour la **séance 2**, créez un Codespace avec la configuration **« Séance 2 —
   Mesurer un LLM »** (*Code → Codespaces → ⋯ → New with options*) : Python et
   Ollama s'y installent, avec le modèle.
2. Vérifiez que GitHub Copilot est actif sur votre compte (offre GitHub Education).
3. Ouvrez le guide de la séance du jour.
